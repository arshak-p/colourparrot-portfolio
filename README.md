# Colour Parrot Agency

A high-end, premium agency website built with React, Vite, and GSAP.

## 🚀 Features

- **Modern UI/UX**: Cinematic animations and transitions using GSAP.
- **Dynamic Backgrounds**: Starfield and cosmic aesthetics.
- **Responsive Design**: Fully optimized for all screen sizes.
- **Performance**: Built with Vite for lightning-fast development and optimized production builds.

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Animations**: [GSAP](https://greensock.com/gsap/)
- **Styling**: Vanilla CSS / CSS Modules
- **Routing**: [React Router](https://reactrouter.com/)

## 📦 Getting Started

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/colourparrot.com.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗️ Building for Production

To create an optimized production build:

```bash
npm run build
```

The output will be in the `dist/` directory.
